What is needed to activate this?

Real credentials and a secure backend are required.

  • Create a project in Primus Developer Hub to obtain an app ID and app secret.
  • Keep the app secret on a server-side environment variable; never publish it in frontend code.
  • Choose a supported data source and configure its request/response template.
  • Implement SDK attestation generation and verification, then test with real proofs.
